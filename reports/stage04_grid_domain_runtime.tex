\section{Stage 4: Grid/Domain Sensitivity and Runtime}

\subsection{Purpose}
This stage audits numerical stability before any surrogate dataset construction. It measures how grid refinement and domain truncation affect price, early-exercise boundary, Delta, Gamma, obstacle and complementarity diagnostics, shape diagnostics, PSOR iterations, and runtime for a base American put and a dividend-paying American call.

\subsection{Method}
The experiment runs both option cases from a shared convergence configuration. Grid refinement uses $M=N\in\{40,80,120,160,240\}$ on the reference domain $S_{\max}=4K$. The finest grid, $M=N=240$, is used as the stage reference. Domain sensitivity uses $S_{\max}\in\{3K,4K,5K\}$ at $M=N=120$ and compares the stable reporting region $S/K\in[0.4,1.8]$ against the same reference surface.

Coarser price, Delta, and Gamma surfaces are interpolated onto the reference tensor-product grid before errors are computed. Boundary errors are computed only at time levels where both the candidate and reference curves have status \texttt{boundary\_found}. Delta and Gamma errors use the Stage 3 strict Greek mask, which excludes the payoff kink, free-boundary band, and near-zero spot region.

\subsection{Mathematical Formulation}
For a computed surface $U_h(S_i,\tau_n)$ and reference surface $U_{\mathrm{ref}}(S_i,\tau_n)$, the reported price error on the final time level is
\[
\mathrm{RMSE}(U_h,U_{\mathrm{ref}})=
\left(\frac{1}{|\Omega|}\sum_{(i,n)\in\Omega}
\left(U_h(S_i,\tau_n)-U_{\mathrm{ref}}(S_i,\tau_n)\right)^2\right)^{1/2},
\]
where $\Omega$ is either the final-time reporting region for price or the strict-mask region for Greeks. Boundary errors compare the extracted early-exercise boundary $B_h(\tau)$ against $B_{\mathrm{ref}}(\tau)$:
\[
\mathrm{MAE}(B_h,B_{\mathrm{ref}})=
\frac{1}{|\mathcal{T}|}\sum_{\tau\in\mathcal{T}} |B_h(\tau)-B_{\mathrm{ref}}(\tau)|,
\]
with $\mathcal{T}$ restricted to shared \texttt{boundary\_found} levels.

\subsection{Results}
Price errors decrease clearly under grid refinement. At grid 40, the put final-time regional price RMSE is $8.0198\times10^{-4}$ and the dividend-call RMSE is $5.5487\times10^{-4}$. At grid 160, the corresponding errors fall to $4.7205\times10^{-5}$ and $3.7459\times10^{-5}$ before reaching zero by definition on the grid-240 reference.

Runtime increases with grid size. The put runtime rises from $0.0341$ seconds at grid 40 to $0.8493$ seconds at grid 240. The dividend-paying call runtime rises from $0.0342$ seconds to $1.1688$ seconds. Mean PSOR iterations decrease mildly for the put as the grid refines and remain below 10 for the dividend-paying call at the finest grid.

Domain sensitivity is modest on the reporting region. For the put, the domain-study price RMSE ranges from $4.7194\times10^{-5}$ to $1.1253\times10^{-4}$, with initial boundary values $0.8000K$, $0.8000K$, and $0.7917K$ for $S_{\max}=3K,4K,5K$. For the dividend-paying call, the price RMSE ranges from $3.7389\times10^{-5}$ to $9.1275\times10^{-5}$, with initial boundary values $1.3500K$, $1.3333K$, and $1.3333K$.

\subsection{Failure Modes and Limitations}
Boundary error remains grid-limited because the extracted boundary is tied to the uniform spot mesh. Gamma is the weakest convergence quantity even under the strict mask, which is expected because second derivatives amplify interpolation and nonsmooth-payoff effects. This stage uses the grid-240 solution as an engineering reference, not an external high-resolution or analytic benchmark. Rannacher smoothing is still not active, so near-maturity Gamma should remain restricted in any claims.

\subsection{Conclusion and Next Step}
The Stage 4 gate passes for continuing classical application risk-surface experiments. The evidence supports using the current solver for engineering-scale American put and dividend-paying call studies, with attached diagnostics and explicit limitations. It does not support publication-grade convergence claims or unmasked Gamma claims.
